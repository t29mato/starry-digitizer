# UI Refresh Spec — StarryDigitizer (機能不変・見た目と導線の全面刷新)

作成: HQ/Fable 2026-08-27(本番UIの実見スクリーンショットに基づく)。HQ Issue #56。
**原則: 機能・ロジックは一切変えない。** 変えるのはレイアウト・視覚階層・文言・発見可能性のみ。

## 現状の診断(本番 v1.13.3)

1. **導線が見えない**: 初見ユーザーには「何を最初にすべきか」が分からない。左に小さな入力群、右に抽出設定が同時に見え、順序の手がかりがない
2. **発見可能性の欠如**: クリップボード貼り付け・拡大鏡など強力な機能が実装済みなのにUIが宣伝していない(オーナーですら気づかなかった実績 #40/#41)
3. **視覚密度が高すぎる**: 8px未満の余白、ラベルなしアイコンボタン、大文字小文字が混在する小さなキャプション
4. **プライマリアクションが埋没**: RUN(自動抽出)とCOPY TO CLIPBOARD(成果物)が他のコントロールと同じ重みで置かれている

## デザイン方針

### 1. ワークフロー・ファーストの左レール(最重要)
左サイドバーを**番号付きステップのアコーディオン**に再編する:

- **① Image** — アップロード。空状態では中央キャンバスに大きなドロップゾーン:「Drag & drop, paste (⌘V), or choose an image」(貼り付け機能をここで宣伝)。サンプル画像は「Try with sample」リンクに格下げ
- **② Axes** — XY Axes List+x1/x2/y1/y2+calibration mode+Log。ステップ見出しに完了チェック(4点設定済みなら✓)
- **③ Extract** — Manual(ADD/EDIT/DELETE)とAutomatic(アルゴリズム選択+設定)をタブで。**RUNはこの領域唯一のfilledプライマリボタン**
- **④ Data & Export** — データセット一覧+X/Yテーブル+Copy CSV/Export。成果物の出口を1箇所に

現在のステップを左端の縦プログレスバー(1-2-3-4)でハイライト。クリックで各セクションへ。

### 2. 視覚システム
- 余白: 8pxグリッド(セクション間16px、カード内12px)
- タイポ: セクション見出し 13px/600、ラベル 12px/500(sentence case、ALL CAPS廃止)、入力値 13px tabular-nums
- 色: 背景 #FAFAFA、カード #FFFFFF+1px #E0E0E0、**アクセントは既存ブランドの青1色(#1E88E5)** — プライマリボタン・アクティブステップ・フォーカスのみに使用。破壊的操作(DELETE/CLEAR)はoutlined+赤文字
- アイコンボタンは必ずツールチップ付き、主要操作はアイコン+ラベル

### 3. ヘッダー(アプリバー)
現在の浮いた「Project」メニューを高さ48pxのアプリバーに: 左=ロゴ+プロジェクト名(保存/読込)、中央=Undo/Redo(PR #248のボタンをここに常設)、右=ズームコントロール(-/100%/FIT/+)と設定歯車

### 4. 右パネル
拡大鏡を上部に固定(現状維持)、その下に「Cursor readout」(x,y値)をカード化。Infinity表示は画像未キャリブレーション時は「—」に

### 5. フッター
青帯を廃止し、細い1行(リンク+バージョン)のニュートラルなフッターに

### 6. 実装ノート
- 既存コンポーネントの再配置を基本とし、ロジック層(application/domain)には触れない
- Vuetifyのまま。テーマ変数でアクセント一元化
- E2E(既存+#43で追加分)が全通過すること=機能不変の証明
- Before/Afterスクショ(デスクトップ1512px・1024px)をPRに添付
